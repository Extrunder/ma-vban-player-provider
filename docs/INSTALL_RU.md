# Установка community provider на Home Assistant OS

Этот вариант использует официальный Music Assistant. Пересобирать его образ и копировать
Python-файлы в контейнер не требуется.

## Что должно быть готово

- Репозиторий провайдера опубликован на GitHub и имеет обычный релиз.
- Провайдер принят в [community catalog](https://github.com/music-assistant/community-catalog).
- Версия/канал MA поддерживает каталог, предлагающий для него этот провайдер.

**В MA 2.10.13 установщика community provider нет.** Подготовка проекта не добавляет
такую возможность в 2.10.13 и не обновляет ваш сервер. Для предварительной проверки есть
отдельная официальная App **Music Assistant DEV SERVER**, параметр **Provider repository**.

## После публикации и приёма в каталог

1. Войдите в MA под администратором.
2. Откройте Marketplace, включите community catalog и подтвердите его предупреждение.
3. Найдите **VBAN Player**, установите его и добавьте экземпляр провайдера плеера.
4. Укажите IP приёмника, порт `6980`, имя `MusicAssistant`, `48000` Гц, stereo, `16` бит
   либо другие параметры, совпадающие с вашим приёмником.
5. В Voicemeeter включите VBAN и соответствующий Incoming Stream. Имя потока учитывает
   регистр; в IP From должен быть разрешён IP отправителя MA. Выберите входную полосу и выход.
6. Выберите новый плеер в MA и запустите воспроизведение.

Параметры меняются через **Reconfigure**. Для второго приёмника добавьте второй экземпляр.

## Обновление и переустановка

Файлы и сведения об установленном community provider управляются MA и хранятся отдельно
от пакета Python в образе. Обновление образа/пересоздание контейнера сохраняет их,
**если сохраняются постоянные данные MA**. Каталог проверяет совместимость версий.

Удаление MA с удалением данных — чистая установка: провайдер и настройки нужно
восстановить из резервной копии либо установить заново. Плагин не может сохранить
настройки внутри уже удалённых данных приложения.

Репозиторий: [Extrunder/ma-vban-player-provider](https://github.com/Extrunder/ma-vban-player-provider).
Приём в каталог ещё не завершён. ZIP — исходники GitHub-релиза, а не файл для загрузки через MA.
